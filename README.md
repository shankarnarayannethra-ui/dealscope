# DealScope Intelligence — Polished Edition

A static, multi-page M&A research dashboard built with HTML, CSS, JavaScript, Python, and GitHub Actions.

## Highlights
- Responsive editorial design with light/dark modes
- Navy text on the original warm light-mode background
- Curated deals and clearly labeled automated news discoveries
- Deal scorecards, bull/bear cases, timelines, watchlist, and comparison
- SVG data visualizations with no charting dependency
- Interactive synergy break-even calculator
- Company acquisition histories and learning center
- Scheduled GitHub Action for news refreshes

## Run locally
Open the folder in VS Code and launch `index.html` with Live Server.

## Publish
Push to GitHub and enable GitHub Pages from the `main` branch and `/root` folder.

## Important
Automated headlines are discovery records, not fully verified research. Review the original source before relying on transaction terms.
